    Messages sent while working

    New messages wait in a queue and go out together when the current task finishes. A small, fast model checks each one and suggests interrupting when it looks urgent. It never interrupts without asking you.

    Other calendars (ICS)

    Paste read-only calendar feed URLs, one per line, optionally named as Name | URL. Outlook, iCloud, Fastmail and Google all offer an ICS link.

    People

    Models can look people up in Google Contacts (above) and in vCard files, and keep notes about people in a local notebook.

    MCP servers

    Servers added here work with every provider: Claude Code gets them directly, and the API models call them through the harness.

    Browser actions always ask you first.

    Claude Code plugin marketplace

    Plugins install into Claude Code. Any MCP servers they include are also added here for the API models.

    Gemini CLI extensions

    Paste an extension's GitHub URL from the Gemini CLI extensions gallery. Its MCP servers are imported from gemini-extension.json.

    Model routing

    Pick auto as the model and a small model chooses small, medium or large for each message. A chat moves up when a task needs it and stays there, so the prompt cache keeps working.

    Usage limits

    When a provider runs out, work waits for the reset and the chat offers to switch to another provider. Queued and resumed work stops early to keep a reserve for your new instructions.
